Each piece configuration supports piece-wise meta information. For pieces that are selectable (such as shared pieces like stages or personal pieces such as fighters), there are three major configurations allowed.

- Game Controlled - A game may have it's own selection algorithm 
(such as pick/ban)
- Preselected - The selection may select the pieces before hand
- Normal - Supports basic validation such as count, uniqueness and ban list. Also supports custom validation scripts. Theres also a merging algorithm which is mandatory for shared pieces
